# Imagens do produto

Suba aqui, pelo GitHub (botão "Add file" → "Upload files" nesta pasta),
os arquivos com exatamente estes nomes — a página já está referenciando-os:

| Arquivo        | Onde aparece                          | Formato sugerido |
|----------------|----------------------------------------|-------------------|
| `hero.png`     | Imagem grande de destaque no topo (hero) | Retrato ou paisagem, PNG/JPG, largura mínima 900px |
| `card-1.png`   | 1ª carta na tira abaixo do hero        | Retrato (proporção ~3:4), PNG/JPG |
| `card-2.png`   | 2ª carta na tira                       | Retrato (proporção ~3:4), PNG/JPG |
| `card-3.png`   | 3ª carta na tira                       | Retrato (proporção ~3:4), PNG/JPG |
| `card-4.png`   | 4ª carta na tira                       | Retrato (proporção ~3:4), PNG/JPG |
| `card-5.png`   | 5ª carta na tira                       | Retrato (proporção ~3:4), PNG/JPG |

Até você subir os arquivos, esses espaços aparecem vazios/quebrados na página —
isso é esperado, é só assim que fica até você adicionar suas próprias imagens.

Se usar nomes ou formatos diferentes (ex.: `.jpg`), ajuste os `src=""` correspondentes
em `index.html` (seção `<!-- HERO -->`).
